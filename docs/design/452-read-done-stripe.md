# 452 — '다 읽음'을 논문 가져오기 목록에서 눈에 띄게 (0.3.473)

## 문제

보관함에 있는 논문은 논문 가져오기 목록에서 초록 테두리로 잘 보인다. '다 읽음'(design/442)은 작은 연한 배지뿐이라 잘 안 보였다.

## 바꾼 것

- 다 읽은 줄은 왼쪽 끝에 굵은 파란 세로 띠(6px)가 붙는다 (`ReadDoneStripe`, 낱개 줄과 메인+SI 세트 줄 모두). 초록 테두리는 그대로라 둘이 함께 보인다.
- '다 읽음' 배지는 파란 테두리, 진한 파란 글씨, 조금 큰 글자(12, 굵게)로 바꿨다. 같은 배지를 쓰는 보관함 화면도 같이 바뀐다.
- 색은 하나: `kReadDoneColor` (파랑). 초록(이미 보관)과 섞이지 않는다.
