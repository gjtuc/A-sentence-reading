# 482 — 시작 표시는 3초에 걸쳐 사라진다

## 문제

design/480 의 시작 표시(첫 줄 왼쪽 옅은 막대)는 문장이 바뀔 때 한 번 밝아진 뒤 밝기 16% 로 계속
남아 있었다. 표시가 쓸모 있는 때는 문장이 바뀐 순간뿐이다(눈이 첫 글자에 닿기까지 약 0.3초). 그 뒤로는
읽는 동안 눈가에 걸리기만 한다. 줄이 바뀌면 눈은 다음 줄 시작으로 가므로 첫 줄 표시와는 상관이 없다.

## 방침

- `StartMark.life` 3초. 0.1초 동안은 옛 문장이 흐려지는 중이라 기다리고, 0.21초에 가장 밝고(55%),
  0.7초에 16% 로 내려온 뒤 멈추지 않고 3초까지 옅어져 0 이 된다.
- 머무는 구간을 두지 않는다. 머물다 사라지면 사라지기 시작하는 순간이 눈에 띈다. 끝부분은 천천히
  줄어(`easeInOut`) 툭 꺼지지 않는다. 사라지는 것은 나타나는 것보다 눈을 훨씬 덜 끈다.
- 같은 문장으로 돌아오면 다시 처음부터 보인다.

## 확인

`mobile/test/sentence_anchor_480_test.dart` — 밝아짐, 3초 동안 계속 줄어듦, 3초 뒤 0.
