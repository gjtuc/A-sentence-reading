# design/508 — 발음 기준 소리는 연습 중인 문장 앞 5개만 미리 만든다 (0.3.518)

## 문제

- 30일 동안 Google 음성 합성 11,327번 중 10,274번(91%)이 발음 기준 소리(`v1beta1`, design/378)였다. 실제로 들은 읽어주기(`v1`)는 1,053번.
- 분석이 끝날 때와 휴대폰에서 논문을 열 때마다 논문 전체(최대 600문장)를 문장마다 두 번씩 합성했다. 대부분 연습하지 않을 문장이었고, 그동안 서버가 몇 시간씩 켜져 있었다.

## 결정

- 서버 `_warm_sound_refs`는 받은 문장 중 앞 `_SOUND_WARM_AHEAD`(5)개만 만든다. 예전 앱이 600문장을 보내도, 분석 끝 자동 요청도 같다.
- 만드는 중에 같은 논문의 새 요청이 오면 가장 최근 것 하나만 `_WARM_NEXT`에 두고, 지금 일이 끝나면 이어서 만든다. 예전에는 버렸다.
- 앱은 논문을 열 때 `soundWarmAhead`로 커서부터 5문장만 보내고, 연습 화면 `_bindSentenceAt`에서 문장이 바뀔 때마다 `warmSoundAhead`로 다음 5문장을 보낸다. 같은 위치는 두 번 보내지 않는다.
- 이미 만든 기준 소리는 캐시에서 읽힌다. 한 번 연습한 문장은 다시 돈이 들지 않는다.

## 시험

- `mobile/test/sound_warm_order_test.dart` — 창 계산, 열 때와 연습 화면이 창만 요청.
