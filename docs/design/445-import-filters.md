# 445 — 논문 가져오기 필터 두 개 (0.3.470)

## 문제

논문 가져오기 화면의 칩은 '전체'와 '미보관만' 중 하나만 고르는 방식이었다.
design/442 로 '다 읽음' 표시가 생겼지만 다 읽은 논문을 목록에서 뺄 방법이 없었다.

## 바꾼 것

- '전체' 칩을 없앴다.
- '미보관만'과 '안 읽음만'은 각각 켜고 끄는 필터다 (`FilterChip`).
  - 둘 다 끄면 폴더의 모든 PDF.
  - 둘 다 켜면 보관함에 없고 다 읽지도 않은 PDF.
- 고른 상태는 기기에 기억한다 (`pdf_import_unkept_only_v1`, `pdf_import_unread_only_v1`).
- 필터에 맞는 PDF가 없으면 '필터에 맞는 PDF가 없어요. 위 필터를 꺼 보세요.'

## 규칙

- '안 읽음만'은 목록 줄 단위로 거른다 (`withoutReadDone`, `pdf_folder_grant_models.dart`).
  본문+SI 묶음은 본문 파일로 판단한다. 본문을 다 읽었으면 묶음째 빠지므로 SI만 따로 남지 않는다.
- 해시를 아직 계산 중인 파일은 판단할 수 없으므로 남긴다.
- 해시는 대소문자를 가리지 않는다.
