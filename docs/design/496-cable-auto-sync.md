# design/496 — 선을 꽂으면 알아서 동기화, 설치 안내 ② 고치기 (0.3.509)

## 왜

- design/495 의 도우미가 있어도 사용자는 웹과 휴대폰에서 각각 동기화 단추를 눌러야 했다.
- 크롬은 서명 없는 처음 보는 exe 를 「의심스러운 파일 차단됨」으로 막는다. 안내 ② 가 그 화면과 달랐다.
- 동기화 단추는 남긴다 (맥, 도우미를 못 까는 PC, 선이 없는 사람).

## 무엇

### 도우미 (`scripts/usb_sync_bridge.py`, `HELPER_VERSION = "2"`)

- `/watch`: 웹 페이지가 열려 있는 동안 붙잡고 있는 선. Origin 규칙은 `/store` 와 같다.
- 안부(hello)에 `watch` (지켜보는 웹 페이지가 있나) 와 `phone` (휴대폰이 도우미에서 기다리나) 이 붙는다. 휴대폰 확인 포트(47817)도 같은 안부를 준다.
- 휴대폰이 다리(47816)에 붙었는데 웹이 아직 없으면, 지켜보는 웹 페이지에 `{"t":"phone"}` 을 보낸다.

### 휴대폰 (`PhoneCableWatcher`, 안드로이드, 앱이 화면에 있을 때만)

- 3초마다 확인 포트를 묻는다. 답이 오고 `watch` 가 참이면 `NearLink.join()` 을 시작한다.
- 꽂을 때마다 한 번. 두 번 연속 답이 없으면(선을 뺐다) 다음 번을 허락한다. 마지막 자동 동기화 5분 뒤 앱으로 돌아와도 다시 한다.

### 웹 (`WebCableWatcher`)

- 조용히 연결해도 될 때만 (`_mayTryQuietly`, design/495) `/watch` 를 연다. 끊기면 15초부터 두 배씩, 최대 5분 간격으로 다시.
- `{"t":"phone"}` 이나 안부의 `phone: true` 에 `NearLink.host()` 를 시작한다. 한 번에 하나.

### 앱 공통 (`LibraryController`)

- 첫 목록 새로고침이 된 뒤 감시를 켠다. `makeNearLink` 는 동기화 단추와 같이 쓴다.
- 동기화 창이 열려 있거나 자동 동기화 중이면 겹치지 않는다. 자동 중에 단추를 누르면 "지금 휴대폰과 맞추는 중이에요."
- 40초 안에 주고받기가 시작되지 않으면 그만둔다 (휴대폰이 3분 기다리지 않게).
- 알림은 짧은 아래 띠: "휴대폰과 맞추는 중…" → "휴대폰과 맞췄어요 · 받은 논문 N개, 보낸 논문 M개" (같으면 "휴대폰과 같아요"). 안 되면 "자동으로 맞추지 못했어요. 동기화 단추로 다시 해 주세요."
- 증거 `near_sync_done` 에 `auto: 1`.

### 설정 칸

- 설치 안내 ② 를 크롬 「의심스러운 파일 차단됨」 → 「다운로드」, 엣지 「…」 → 「유지」 로 바꾸고 ⑥ 까지 다시 번호를 매겼다.
- 웹 안내에 "설치하고 나면, 웹과 휴대폰 앱을 열어 둔 채 선을 꽂을 때 알아서 맞춰요."
- 연결된 도우미가 버전 2 보다 낮으면 "새 도우미가 나왔어요. 「도우미 받기」로 다시 받아 설치해 주세요." (휴대폰은 "컴퓨터 웹의 설정에서").
