# 453 — 숨긴 논문은 20초 뒤 영구 삭제 (0.3.474)

## 바꾼 것

보관함에서 논문을 지우면 "N건을 숨겼습니다. ~초 후 영구 삭제됩니다." 가 뜨고, 그동안 되돌릴 수 있다(design/224).
그 기다림이 60초였는데 너무 길다고 해서 20초로 줄였다 (`kSoftDeleteGrace`).
알림의 남은 초와 표시 시간은 같은 값에서 계산한다. 화면에 따로 적혀 있던 60 두 곳도 이 값을 쓴다.

동기화(design/450)는 영구 삭제된 뒤부터 지우기를 퍼뜨리므로, 이제 지우고 20초 뒤면 된다.
