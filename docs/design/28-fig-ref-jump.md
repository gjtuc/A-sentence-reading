# 28 — Fig. N → 그림 점프 힌트

모듈: `fig_refs.py` · `static/fig_refs.js` · 문장 패널 칩

## 무엇을

본문에 `Fig. 2` / `Scheme 1` / `Table 3` 이 있으면,  
캡션이 맞는 캐러셀 칸으로 **가는 칩**을 문장 아래에 띄운다.

| 동작 | |
|------|--|
| 칩 클릭 | `figure_index` 만 이동 (문장 불변) |
| 자동 강제 점프 | **안 함** — 힌트만 |
| 매칭 실패 | 칩 없음 |

## 매칭

정규화 키: `fig|scheme|table` + `S?\d+[a-z]?` (대소문자 무시).  
캡션 앞머리(`Fig. 2 — …`)와 본문 참조를 같은 키로 비교.

복합 `Figs. 1 and 2` · `1a/1b` 분해는 **이 턴 범위 밖** (compound는 통짜).

## UI

문장 프레임 아래 `#figRefHints` — ghost 칩.  
이미 그 그림이면 `is-current`.

## 불변

- 문장↔그림 인덱스 독립 (클릭으로 그림만)
- AI 채점/힌트 문장 없음 — 참조→그림 네비만
