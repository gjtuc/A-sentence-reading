# 488 — 논문이 아닌 문서도 제목을 고른다

## 문제

- 심사 기록 PDF(MOESM2)의 제목이 "Microsoft Word - review 0.docx"였다. `pick_session_title`은
  Azure → Info.Title → 가장 큰 글씨 → 본문 첫 문단 순서인데, 워드가 넣은 Info.Title이 통과했다.
- 한글 문서는 거의 다 제목이 엉뚱했다("PEM… 7 5 0 0 2 28.6%"). `is_title_chrome`이 앞쪽의
  영어 알파벳이 아닌 글자를 모두 지우고 판단해서, 한글로만 된 줄은 빈 줄 = 잡동사니가 됐다.
- 모든 글자가 한 크기인 문서는 "가장 큰 글씨"가 곧 본문이다.

## 방침

- `clean_info_title`:
  - 떼어 내는 것: "Microsoft Word/PowerPoint/Excel - " 앞머리, " - Google Docs" 꼬리
  - 버리는 것: 파일 이름(.docx, .pdf, .xlsx 등으로 끝남), 기본 이름("PowerPoint 프레젠테이션",
    "Untitled")
- `is_title_chrome`은 모든 문자의 글자를 글자로 본다(`^[\W\d_]+`만 떼어 낸다).
- 잡동사니로 보는 줄:
  - 날짜만 있는 줄(`_DATE_LINE`)
  - "번호: 314-82-…" 같은 서식 칸(`_FORM_FIELD`)
  - `*` 또는 `※`로 시작하는 주석
- 가장 큰 글씨는 본문보다 1.15배 이상일 때만 제목이다(`TITLE_FONT_RATIO`).
  - 본문 크기(`body_font_size`)는 앞 3페이지에서 가장 많은 글자가 쓰인 크기다.
  - 표지는 글이 적어 제목 크기가 가장 많을 수 있어서, 첫 페이지만 보지 않는다.
- 위가 모두 실패하면 지금처럼 본문 첫 문단(맨 위 글 뭉치), 그다음 파일 이름이다.

## 확인

- 다운로드 폴더 PDF 186개를 바꾸기 전과 후로 비교했다.
  - 바뀐 것은 61개로, 모두 논문이 아닌 문서와 MOESM2, 포스터다.
  - 논문 제목은 바뀐 것이 없다.
  - 사업자등록증 같은 서식 문서 몇 개는 여전히 서식 줄이 제목이 된다. 제목 고치기(다음 단계)로 푼다.
