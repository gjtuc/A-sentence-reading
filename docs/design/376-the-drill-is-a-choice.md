# 376 — 틀린 단어 다시 읽기는 고를 수 있어야 한다

## 왜

말하기 한 번이 끝나면 틀린 단어를 다시 읽는 순서가 붙는다. 그 순서는 단어를 틀렸다고
표시하는 이유 자체이므로 기본은 켜짐이다. 하지만 그것은 시간을 쓰는 유일한 순서이기도
하고, 문장을 빠르게 넘기고 싶을 때는 방해가 된다.

읽는 사람이 직접 요청했다. design/364 의 발음 표본 행과는 다르다. 그건 숨기면 할 것이
없어지는 행이어서 설정이 아니라 서버 플래그로 끈 것이고, 이건 끄든 켜든 연습이 그대로
돌아간다.

## 잠금

### 채점은 스위치를 모른다

끄기는 **채점 뒤에** 읽힌다. 단어는 여전히 틀렸다고 표시되고, 점수에 그대로 들어가고,
통과선의 `line_n` 도 그대로 오른다. 바뀌는 것은 다시 읽는 순서를 걷는지 뿐이다.

이 순서가 중요하다. 반대로 짜면 — 끄기를 채점보다 먼저 읽으면 — 연습을 거부하는 것이
등급을 올리는 길이 된다. 스위치가 있는 이유와 정반대다.

시험이 이것을 지킨다: `missReviewWords` 는 같은 입력에 같은 목록을 돌려주고, 스위치는
그 목록을 걷는지만 정한다.

### 기본은 켜짐, 읽기 전에도 켜짐

`_missReviewOn` 은 `true` 로 시작한다. 저장된 값을 읽는 것은 비동기이므로, `false` 로
시작하면 읽기가 늦은 동안 연습 하나가 조용히 건너뛰어진다. 끄기를 요청한 적 없는 사람이
끄기를 받는 것이 더 나쁘다.

### 이름을 바꾸지 말 것

`asr.practice.miss_review`. 이 글자를 바꾸면 기본값이 바뀌는 게 아니라 **지금까지 한
선택이 전부 사라진다** — 옛 이름이 값을 들고 있고 아무도 읽지 않으므로, 끈 사람 전부가
다시 켜진 상태로 돌아간다. 시험이 이 글자를 고정한다.

접두사도 이웃과 같다(`asr.practice.`). 연습 설정을 한 번에 지울 때 이것만 남지 않는다.

## 어디에 있나

| 자리 | 하는 일 |
|---|---|
| `mobile/lib/practice_rhythm/miss_review.dart` | `kMissReviewPrefKey` |
| `mobile/lib/screens/settings_screen.dart` | 따라 말하기 아래 스위치 |
| `mobile/lib/screens/shadowing_practice_screen.dart` | `_missReviewOn`, `review_reason: 'review_off'` |

연습 화면은 세 군데에서 값을 다시 읽는다: 처음 켤 때, 앱으로 **돌아올 때**, 집중을 다시
시작할 때. 돌아올 때 읽는 것이 설정을 바꾸고 나와도 앱을 다시 켜지 않아도 되는 이유다.

## 로거가 말해주는 것

끈 상태에서 틀린 단어가 있는 말하기는 `review_reason: 'review_off'` 를 남긴다.
`no_missed_words`(틀린 게 없었다) 와 `score_timeout`(채점을 못 기다렸다) 와 구별되므로,
연습이 안 붙는다는 신고가 왔을 때 고장과 선택을 섞지 않는다.
