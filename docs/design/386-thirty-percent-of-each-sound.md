# design/386 — 소리 하나의 일치는 30%를 같이 넘기는 것

## 규칙

원어민 칸에서 공백을 빼고 30% 이상인 기호가 있으면, 사용자도 그 기호를 **전부** 30% 이상 가지고 있어야 그 소리 하나가 일치다. 하나도 없으면 그 소리는 일치가 아니다.

단어 점수는 그대로다.

점수 = 일치 수 / max(원어민 소리 수, 사용자가 말한 소리 수)

말한 소리 수에 공백은 넣지 않는다.

## 619개 녹음

소리 16,079개.

| | |
|---|---|
| 30% 넘는 기호가 하나 | 95.6% |
| 둘 이상 | 3.1% (491) |
| 없음 | 1.3% (212) |

둘 이상인 칸에서, 사용자는 그중 하나를 70% 이상으로 말했는데 나머지는 30%가 안 된 경우가 138번이다. 전체 소리의 0.9%다.

제대로 읽은 단어를 90% 살리는 선에서, 틀린 단어는 지금 식이 45%, 이 규칙이 40%를 잡았다.

## 옛 기준

기준 열쇠에 0.30이 들어간다. 그 전에 지은 기준은 이긴 기호만 가지고 있어서, 폰이 다시 받는다. 다시 받기 전에는 그 문장을 채점하지 않는다.
