# UX

페인트 목업과 Immersive Reader 감각을 코드로 옮기기 위한 화면 계약.

## 레이아웃

```
┌──────────────────────────────────────────┐
│  한 문장                 Sent j / M       │
│  [◀]     ┌──────────────┐      [▶]       │
│          │  one sentence │                │
│          │  (narrow col) │                │
│          └──────────────┘                │
├─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┤
│  그림                    Fig i / N        │
│  [◀]     ┌──────────────┐      [▶]       │
│          │   figure     │                │
│          └──────────────┘                │
└──────────────────────────────────────────┘
```

- **상단**: 문장 하나. Immersive Reader식 타이포 (읽기 위치).
- **하단**: 그림 캐러셀. 캡션/번호는 가능하면 표시 (다음 단계).
- **구분선(스플리터)**: 아래로 드래그하면 그림이 접혀 **하단 그림 프레임**만 남고 문장 영역이 커진다. 프레임을 위로 끌면 복원. → [design/11-figure-collapse.md](design/11-figure-collapse.md)

## Immersive Reader 레시피 (문장 패널)

Azure SDK를 쓰지 않고 **CSS로 재현**한다. ([RESEARCH.md](RESEARCH.md) 참고)

| 설정 | CSS 방향 |
|------|----------|
| 어두운 배경 + 밝은 글자 | `--bg: #0f0f0f`, `--fg: #e3e3e3` |
| 좁은 열 | `max-width: ~27ch` (기존 대비 약 4/5) |
| 넓은 간격 | `letter-spacing`, `word-spacing`, `line-height` 증가 |
| 큰 글자 | `font-size` 1.25–1.75rem 대 |

선택 폰트: 시스템 가독 서체 또는 Sitka/Calibri 계열 폴백. Comic Sans는 Immersive Reader 옵션이지만 기본은 쓰지 않는다.

## 네비게이션

| 입력 | 동작 |
|------|------|
| `→` / 하단 ▶ | 다음 문장 |
| `←` / 하단 ◀ | 이전 문장 |
| `Shift+→` / 하단 ▶ | 다음 그림 |
| `Shift+←` / 하단 ◀ | 이전 그림 |
| (선택) `Home` / `End` | 문장 처음/끝 |
| `Tab` / `Shift+Tab` | 열린 논문 탭 전환 (2개 이상) |
| `1`–`9` | 해당 순번 논문 탭 |
| 탭 드래그 | 논문 탭 순서 변경 — 잡은 탭이 커서를 따라감 (크롬식 · 0.2.39) |
| 탭 × | 탭 닫기 — 진행·노트(탭 범위) 저장 후 닫기 · TTS/테마는 유지 (0.2.42) |
| 번역 | 영→한 — EN|KO 좌우 (0.2.47) · **ingest 미리번역만** 표시 (0.2.50 · live 폴백 없음) · 보관본 KO 백필 · 번역 stage 세분 진행 (0.2.51) · progressive 열기 (0.2.53) · 번역 병렬 (0.2.54) |
| 모바일 | Android Flutter · theme/OAuth + access gate OTP(0.2.76) · APK follow-up · Live Enable/IPS none|
| 각주 | `[n]` 칩 → References → 원문 열기 (0.2.49) · **문장 박스에서는 [n] 숨김** · FS에서 Fig처럼 hover (0.2.57 · design/49) |
| 번역 한글 | 어절(공백) 경계 줄바꿈 · `word-break: keep-all` (0.2.58 · design/50) |
| 되새김질 키 | 시트 열림: `←`/`→` 구간 · `Enter` 수정 · `Esc` 취소/닫기 (0.2.64 · design/56) · 인덱스 불변 |
| 되새김질 | 구간 노트를 **한 박스에 이어 보기** (0.2.59 · design/51) · **▶ 이어 듣기** (0.2.60 · design/52) · 헤더「되새김」on/off (0.2.61 · design/53) · 일시 정지 후 이 문장만 다시 듣기/재녹음 (0.2.62 · design/54) · flow 콕 수정 (0.2.63 · design/55) · ←/→·Enter·Esc 키보드 (0.2.64 · design/56) · 흰 십자 (0.2.65 · design/57) |
| 헤더 | **파일 열기** + `⋯` (0.2.66 · design/58) · **Guide** 밖/`⋯` 안 (0.2.67 · design/59) · 패널 단축키 줄 기본 숨김 · Guide에서 켜기 (0.2.76 · design/60) |
| 말하기 | 발음 연습 — 서버 STT 기본 · 브라우저 폴백 · 원문 diff · **점수 없음** (0.2.46) |
| `Alt+←` / `Alt+→` | 활성 논문 탭을 한 칸 이동 |
| `F` | 브라우저 전체화면 토글 (주소창·탭 숨김). 다시 `F` 또는 `Esc`로 종료 |
| (F 모드) `↑` | 바로 글 몰입(전체화면 크기 문장), 부드럽게 |
| (F 모드) `↓` | 바로 그림 몰입(전체화면 크기 그림), 부드럽게 · large 단계 없음 |
| (F + 문장 확대) | 글만 표시. 문장 영역에 마우스를 올리면 라벨·화살표·힌트·그림 프레임 일시 표시 |
| `↓` | 그림 프레임 클릭과 동일 (확대 → 전체화면 → 복귀) |
| `Enter` | 듣고 적기 노트 열기 (+ TTS). 칸 안 Enter 1–2=줄바꿈 · Enter×3=닫기 |
| 노트 열림 · 입력칸 비포커스 `←`/`→` | 저장 후 이전/다음 문장 (창 유지) |
| `Esc` (노트 열림) | 노트 닫기 (브라우저 전체화면보다 우선 · FS 유지). 노트가 닫힌 뒤 Esc로 FS 해제 |
| 문장 박스 클릭 | TTS 재생 (Enter는 노트용) |
| 그림 박스 클릭 | 1회≈78% 확대 · 2회 전체화면 · 3회/Esc 복귀 |
| 그림 전체화면 드래그 | 영역 크롭 확대 · 확대 중 드래그=팬(마우스 **2×**) · 클릭=축소 (0.2.40) |
| 그림 프레임 드래그 ↑ / 클릭 / 스플리터 더블클릭 | 그림 다시 펼침 |
| 스플리터 포커스 + ↓/↑ | 그림 접기/키우기, Enter 토글 |

**INVARIANT:** Shift 없는 화살표는 문장만, Shift는 그림만. 서로 묶지 않는다.  
**INVARIANT:** 그림 접기/펼치기는 **레이아웃만** 바꾸고 인덱스는 건드리지 않는다.

## 접근성 (초안)

- 버튼에 `aria-label`
- 포커스가 문장 패널에 있을 때 키보드 동작이 우선
- 색만으로 정보를 전달하지 않음 (인덱스 숫자 병기)
