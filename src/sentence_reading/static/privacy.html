개인정보 처리방침

문장 읽기 (웹, 안드로이드 앱) · 논문 전송 도우미 (Windows)
시행일: 2026년 11월 1일

1. 모으는 정보

  • Google 계정으로 로그인할 때 받는 계정 고유 번호, 이메일 주소, 이름
  • 사용자가 올린 논문 파일과 그 분석 결과 (문장, 번역, 그림)
  • 읽은 위치, 메모, 책갈피, 따라 읽기 녹음
  • 앱이 어떻게 동작했는지에 대한 기록 (오류, 처리 시간)

2. 정보를 쓰는 곳

  • 논문을 분석하고 번역해서 보여 주기
  • 웹과 휴대폰 사이에서 논문과 읽은 위치를 맞추기
  • 오류를 찾아 고치기

광고에 쓰거나 다른 곳에 팔지 않아요.

3. 처리를 맡기는 곳

  • Google Cloud: 서버 운영, 파일 보관, 논문 분석(Gemini), 번역
  • Microsoft Azure: 논문 쪽 배치(글과 그림의 위치) 인식

4. 보관 기간

  • 계정이 있는 동안 보관해요.
  • 분석을 마친 논문의 서버 사본은 30일 동안 아무 기기도 받아 가지 않으면 지워요.
  • 지워 달라고 요청하면 지체 없이 지워요.

5. 논문 전송 도우미 (Windows)

  • 도우미는 이 컴퓨터 안에서만 일해요. 웹에서 받은 논문 사본과 읽은 위치를 이 컴퓨터의 폴더에 보관하고, USB 선으로 휴대폰과 주고받아요.
  • 도우미가 문장 읽기 서버나 다른 곳으로 보내는 정보는 없어요.
  • 사용자가 도우미 창에서 「휴대폰 연결 도구 받기」를 누르면 Google에서 휴대폰 연결 도구(adb)를 내려받아요.
  • 도우미는 같은 컴퓨터의 문장 읽기 웹 페이지와만 연결돼요.
  • Microsoft Store에서 설치한 도우미를 지우면 보관한 사본도 함께 지워져요.
